# 主题 C · 元模型与建模

## ★ Q13. 宽表 vs 写实 vs 属性表 · 三种建模范式

### 命题
监控数据元模型的三种范式取舍？

### 四方对比

| 方案 | 举例 | 优势 | 劣势 |
|---|---|---|---|
| **宽表** | ServiceNow CI 表 | 简单直观 | 字段爆炸、`ALTER TABLE` 痛 |
| **写实** | 每类实体独立表（TCUM）| 类型强、查询快 | schema 演进僵化 |
| **属性表** | DataHub aspect | schema 演进灵活 | 查询慢、无类型 |
| **混合** | 主字段 + JSON 扩展 | 折中 | 复杂 |

**TCUM 选写实**（iwiki 4013203859 明示原则："**任何软件设计不可能比业务复杂度低**"）

### 改进思路
- **Q13.1（P1）主字段 + JSON 混合**：核心字段类型化 + 长尾字段 JSON

## Q20. 发现大量差异怎么办

- 阈值判断：差异 > 阈值 → 告警人工 → 拒绝自动修复

## Q21. 增量 + 巡检的关系

- 增量 = 快速通道（秒级）
- 巡检 = 慢速兜底（分钟到天级）
- **互补**：增量丢失或错误 → 巡检发现并修复
