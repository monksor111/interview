`build-resume.js` 中的排版构件：

| 构件 | 用途 | 样式 |
|---|---|---|
| `section(标题)` | 分区标题 | 深蓝加粗 12pt + 整行下框线 |
| `entryHead(左, 右)` | 条目主标题行 | 左加粗黑体 10.5pt + 右侧角色/日期加粗 |
| `entrySub(左, 右)` | 条目副标题行 | 灰色 9.5pt + 右侧灰斜体日期 |
| `desc("", 正文)` | 项目概述段（≤2 行） | 缩进无符号 |
| `bullet(导语, 正文)` | 核心子工作 | 深蓝方块符号 + 导语加粗 |
| `gain(正文)` | 业务收益 | 缩进一级 + 深蓝"收益："标签 |
| `skill(类目, 内容)` | 技能行 | 粗体类目 + tab 对齐 + 细线分隔 |

正文中用 `[[文字]]` 包裹的部分会自动加粗，用于突出关键指标数字。

### 项目经历的写法约定（重要）

每个项目严格三段式，不要混写：

1. **概述**（`desc`）：最多两行，说清"项目是什么 + 整体架构思路"，不放任何数字指标
2. **核心子工作**（`bullet`）：粗体 title 精简（4~12 字），后面跟"做了什么 + 怎么做的"，要有具体技术/算法/设计
3. **收益**（`gain`）：紧跟在对应子工作下方，只放该子工作带来的业务价值与量化结果
