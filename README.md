## 使用规则

- 优先从“项目专题”的 `00-索引与使用说明.md` 进入相应专题。
- 同一主题的旧版本只保留在 `90-总册与草稿` 或 `99-归档`，正式内容不再与旧稿混放。
- 新资料按用途放入现有一级目录；项目材料继续按“机制原理、场景案例、项目题库、复盘与表达”归类。
